## Rendering all 66 library demos to watchable mp4

Goal: user wants to *watch* every style to pick one for episode 2+. Output lives at
`Z:/UserFilesData/Videos/抖音创作/vibe知识大赏/_风格库预览/` (src/ = copied demos, mp4/ = films,
tools/ = my helper scripts + logs). Docs written up in `_风格库预览/tools/README.md`.

**The library ships zero demo assets.** 66 demos reference 489 font files and a pile of
photos / HDR maps / numbered frame plates; all absent. Because `main.js` typically does
`await document.fonts.load(...)`, a 404 makes that Promise *reject* and the frame never
renders -- so every referenced path must hold a *valid* font file, real or stand-in.

Three gotchas that cost the most time:

1. **Exit status lies.** `video.mjs` renames its finished merge to `--out` and only then
   deletes its scratch dir. This machine's delete guard allows only **50 file removals per
   tool call**, and each render deletes 10-12, so cleanup eventually throws and the process
   exits non-zero *after* the film is complete. Judge success by "mp4 exists and ffprobe
   reads a duration > 1 s", never by exit code. Leftover scratch dirs are moved into
   `mp4/_segs_trash/` with `mv` (moving is not deleting), for the user to clear.
2. **Font references hide in three forms**, and each needs its own pattern:
   `url(fonts/X.ttf)`; a bare `url(X.ttf)` inside `fonts/fonts.css` (relative to the
   *stylesheet*, not the page); and bare names in a `kit/` sub-page
   (briefing-board resolves fonts relative to `kit/`). One `fonts/`-anchored regex
   silently misses the last two -- it caught only 32 of 66 demos until fixed.
   Also: font filenames can contain square brackets (`JosefinSans[wght].ttf`).
3. **~1.3 s per frame is normal** at 1080p. Budget ~2-6 min per 40 s film at 8 workers.
   Heavy WebGL demos (brick-toy, desktop-flythrough) can exceed the renderer's 30 s
   per-frame screenshot timeout -- retry those with `WORKERS=2` or `SIZE=1280x720`.

Fonts resolved: 65 of 66 demos get real typefaces; 22 styles fall back to a Noto Sans SC
subset (LXGW WenKai / Marker Gothic are not on Google Fonts and GitHub is unreachable).
game-show and halftone-dossier reference 391 opaque shards (`f0..f391`) that cannot be
mapped to a family -- all substituted with one shared subset.
