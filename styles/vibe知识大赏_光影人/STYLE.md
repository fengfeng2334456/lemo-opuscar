# vibe知识大赏_光影人（Guangying Ren）

> 深夜的房间里只有一块手机屏亮着——近黑的空间、纯黑的剪影人物、屏幕是唯一光源，白字字幕是真正的主角。为「vibe知识大赏」竖屏口播/独白类内容而设。

风格曾用名：暗室微光 Low Light（slug `low-light`）。机器可读名：**slug `guangying-ren`**，命令里的目录名即 `vibe知识大赏_光影人`。

## 1. 本质

1. **黑暗是画布，光是标点。** 70% 的画面接近纯黑；观众只看见被光定义的东西。
2. **手机屏是唯一光源。** 所有照明（人物轮廓光、环境微光）都从屏幕出发，带轻微呼吸/闪烁。
3. **字幕是主角。** 一句一屏，白字居中，关掉声音也能看懂；屏显文字 = 全部叙事。
4. **人物是剪影，不是角色。** 纯黑、无细节，姿态表达情绪（弓背低头看手机 = 孤独/焦虑）。
5. **它不是什么：** 不是科普图解（不画结构图）、不是实拍空镜（无照片素材）、不是明亮的知识卡片（不使用亮底）。

## 2. 材质与渲染

- 底：垂直渐变 `#050505 → #0b0907`（底部微暖），叠加静态低透明噪点（420 点，alpha .012–.034）。
- 光：`createRadialGradient` 大半径柔光池（rgba 青白 150,214,230），`shadowBlur` 26–70 做霓虹发光。
- 人物：canvas 粗笔触（lineWidth 40–76，round cap）+ 椭圆体块，纯黑 `#010101`，比背景更黑以区分剪影。
- 轮廓光：头部/手臂沿手机一侧青色细线（5px, shadowBlur 26）；弓背处一条淡红（rgba(224,96,90,.55)）。
- 光环：绕头椭圆细线（262×62，lineWidth 3.5，alpha .55），像轨道。

## 3. 配色

| 用途 | 颜色 |
|---|---|
| 底 | `#050505`–`#0b0907`（近黑） |
| 字幕 | `#e9e6e1`（暖白） |
| 屏幕光 / 轮廓光 | 青白 `rgb(150,214,230)` |
| 卡片霓虹描边 | 青 `rgb(127,216,232)` 或暖橙 `rgb(217,160,90)`（按内容语义选一） |
| 卡片体 | `#0c0a08`，文字 `#f2efe9` |
| 背部 rim（可选） | 淡红 `rgba(224,96,90,.55)` |

配色逻辑：**黑 + 一冷一暖两个信号色**。冷色属于"手机世界"，暖色用于强调/内容卡片，永远不做大面积。

## 4. 字体

- 字幕：Noto Serif SC 400（宋体感，54px），自托管子集 woff2。
- 卡片大字：Noto Sans SC 900（粗黑体，92px）。
- 一律按片内文案用 Google Fonts `&text=` 子集化，禁止整字体打包。

## 5. 运动与节奏

- 动作少而慢：元素淡入/弹入（seg + ease，0.6–1.0 s），出现后静止；没有持续大位移。
- 屏幕光呼吸：`flick = .9 + .1·sin(t·5.3)·sin(t·2.1)`，环境 wash 以 `sin(t·.9)` 慢呼吸。
- 节奏由字幕切换驱动：一句一个节拍，句子出现时间对齐 BGM 鼓点。

## 6. 镜头语法

- 全片固定机位，**无镜头运动**；构图三段式：字幕（y≈23–28%）、内容卡片（y≈42%）、人物（y≈62–92%）。
- 场景切换 = 光源重新布光 + 字幕换句，不做推拉摇移。

## 7. 声音

- 氛围 BGM 垫底（user 指定曲目），可无人声旁白；若加旁白则 BGM duck −6 dB。
- 交付 −14 LUFS / ≤ −1 dBTP。

## 8. 招牌动作

1. **光环亮起**：新句子出现时，绕头椭圆光环以细线画出并停驻。
2. **卡片砸入**：「刷到的视频」卡片 0.96→1 缩放弹入，霓虹描边发光。

## 9. 文案规则

- 一屏一句，≤ 18 字；关键词进卡片（大粗字）或整句白字。
- 可读内容放在 y 380–1560（抖音 UI 安全区之外）。

## 10. 引擎约定

- `index.html` 暴露 `window.DUR`、`window.render(t)`（页面自持 canvas）、`window.READY`（**必须最终 === true 布尔值**，不能是 Promise）、`window.TEXTS(t)`。
- 竖屏 1080×1920；渲染 `LEMO_ANGLE=default node core/render/still.mjs <frame目录> <t> --size 1080x1920`。
- 不用 `roundRect`（老 chromium 兼容，用 arcTo 回退）。

## 11. 禁忌

- 不用亮底、不加实拍素材、不画图表结构、镜头不运动、颜色不超过「黑+白+青+橙红」四个信号。
